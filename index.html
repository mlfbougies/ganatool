GA4 Visites — Outil interne

Cette page décrit une application technique interne développée et utilisée par Groupe LAtelier (Bougies de Charroux).

Cet outil récupère automatiquement, en lecture seule, le nombre de visites quotidiennes de notre site web depuis l'API Google Analytics (GA4), afin de les enregistrer dans notre base de données interne à des fins de suivi statistique.

Il n'est pas destiné à un usage public et n'est utilisé que par des membres autorisés de notre organisation.

Voir notre note de confidentialité concernant cet outil.
